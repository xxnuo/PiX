# 画板改造记录

## 2026-09-23

- 画板拥有独立 ID、名称、分组文件夹、文件夹起始点、会话归属和节点坐标；数据保存在 PiX 的 `gui.settings.json`。旧版 `recentProjects` 首次读取时迁移为一个文件夹对应一个画板，原会话文件保持原位。
- 左侧显示画板与分组；可新建、重命名、移动、删除画板，在当前画板打开多个本地或远程文件夹。删除画板只删除组织关系，不删除文件夹或会话。
- 画板与所有已加入的会话图使用同一画布：文件夹是起始点，每个会话保留自己的图或空会话起点；点击其他会话节点会切换编辑目标，但其余图继续显示、运行，后台运行中的输入与状态也会显示。文件夹及会话节点位置可保存。会话可以只从画板移除而不删除历史文件；fork/clone 产生的新会话会加入画板。
- 主进程按文件夹与会话路径读取图快照，不切换当前会话；后台运行会话的图更新通过独立事件送到画板。画板重载后恢复会话归属与快照。
- 已验证：类型检查；337 项主进程测试、400 项渲染器测试和 PTY 测试；隔离临时目录中的网页界面，两个文件夹、六个会话同时保留。两个文件夹各启动一个新会话，两条请求同时处于运行中；切换到第二个会话后，第一个会话的运行中节点仍显示。分别完成后，两张图都显示回复；重载后会话归属仍在，并能从后台图节点继续第一个会话。当前项目的入口是 Web 服务，旧 Electron GUI 测试所需的项目内 Electron 入口与依赖不可用，因此未完成真实桌面窗口验收。

仍需完成：远程 SSH/WSL 多文件夹的真实连接验收，以及 Electron 窗口验收。主进程仍以每个文件夹作为 Pi 会话的运行目录，这是 Pi 的 cwd 约束。
